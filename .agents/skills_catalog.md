# Agent Skills Catalog

Catalog of custom Antigravity agent skills available in `trmnl-sheet-quote`.

| Skill | Description | Task / Command |
|---|---|---|
| [`conductor_github_sync`](skills/conductor_github_sync/SKILL.md) | Sync Conductor tracks and GitHub issues | `task conductor:sync` |
| [`release`](skills/release/SKILL.md) | Automates versioning, tagging, and deployment process | `task release` |
| [`release-summary`](skills/release-summary/SKILL.md) | Generates clean, professional GitHub release summary from git logs | `task release:summary` |
| [`trmnl_framework`](skills/trmnl_framework/SKILL.md) | Maintain, verify, and update the TRMNL UI framework version in settings.yml | `task verify-framework` / `task update-framework` |
